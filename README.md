# Data Cleaning and Preprocessing

## Project Overview

This project demonstrates data cleaning and preprocessing using the
Hotel Booking Demand dataset.

## Objectives

- Identify and handle missing values
- Detect and remove duplicate records
- Identify invalid values
- Detect numerical outliers using the IQR method
- Visualize outliers using box plots
- Standardize categorical data
- Encode categorical variables
- Compare the dataset before and after cleaning
- Validate the final dataset

## Dataset

Hotel Booking Demand Dataset.

The original dataset contains hotel booking records with numerical and
categorical variables, missing values, duplicate records, and potential
outliers.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Data Cleaning Process

1. Loaded and inspected the dataset.
2. Analyzed missing values.
3. Treated missing values according to variable type and context.
4. Detected and removed exact duplicate records.
5. Detected numerical outliers using the IQR method.
6. Visualized numerical distributions using box plots.
7. Standardized categorical text values.
8. Converted the date field to datetime.
9. Applied one-hot encoding to categorical variables.
10. Compared the dataset before and after preprocessing.
11. Performed final data-quality validation.
12. Exported the cleaned dataset.

## Final Dataset

The final processed dataset contains no missing values and no exact
duplicate rows.
